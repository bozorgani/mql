# Phase 5 — QA Plan
Rule: Never modify code without identifying cause.

Checklist: Compile; logic; risk calc (0.5%); entry accuracy (decision tree); exit (SL/TP/breakeven); position sizing (max 2); unexpected behavior (emergency shutdown).

Bug Report Format: ID / Module / Severity / Cause Identified / Repro Steps / Fix / Verification.

Regression: Re-run checklist after any fix; compare performance template before/after.

Performance Report: Win rate, avg RR, max drawdown, monthly return, consecutive losses, execution time, spread impact.
